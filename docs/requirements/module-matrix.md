# Business modules from the CBC architecture
| Module | UI screens | Core data and logic | Proposed priority |
|---|---|---|---|
| Organizations | directory, profile, create/edit | organizations; linked contacts, giving, activities | MVP |
| Contacts | directory, profile | contacts, organizations, latest activity | MVP |
| Sponsorship & Giving | opportunities, contributions | commitments, payments, giving totals, renewals | MVP subset |
| Activities & Follow-Ups | interaction log, task queue | activities, due dates, owners, overdue status | MVP |
| Sponsor Interests | alignment list | interests linked to programs and opportunities | Later |
| Programs & Recipients | cohorts, recipient outcomes | education and employment KPIs | Later |
| Mentorship | pairing and check-in view | pair health, check-ins, satisfaction | Later |
| Membership | members, renewals | membership status and engagement | Later |
| Documents | uploaded files and links | version/access controls | Later |
| Reports & Executive Dashboard | KPIs and report views | aggregates and report filters | MVP subset |
| Settings | user roles and categories | TBD; menu item is not fully specified | Conditional |

The source PDF includes nine detailed database modules, reports and executive dashboard. This table does not claim every screen is approved for the student MVP.
