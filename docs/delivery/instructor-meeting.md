# Instructor planning meeting
## Decisions to leave with
1. Student count, skills (SQL/BI vs backend/frontend), weekly hours, actual term dates.
2. Track A (data/BI) vs Track B (operational CRM) deliverable.
3. Required demos, acceptance checkpoints and contact/escalation cadence.
4. Allowable tools, platform costs, environments and code ownership.
5. Rules for access to synthetic vs actual CBC data and external presentation.
6. Final release or prototype, CBC maintainer and handoff format.

## Questions
- Is this capstone, class project or placement?
- Can another program support UI, auth and APIs if students are data specialists?
- What constraints or assessment deadlines exist?
- Can the project use this public repo for synthetic/code content only?
- Who approves student access and technical scope changes?
