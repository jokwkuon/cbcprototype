# Acceptance criteria — draft
## Track A
- [ ] Schema recreated from versioned migrations.
- [ ] Approved synthetic CSV/JSON imported reproducibly.
- [ ] Broken references, invalid records and duplicates flagged.
- [ ] Basic foreign-key integrity tests pass.
- [ ] Approved KPIs reconcile to hand-calculated examples.
- [ ] Dashboard presents required filters and metrics.
- [ ] Documentation explains schema, loading, backup and reporting.

## Track B additionally
- [ ] Authorized user creates/updates/searches an organization.
- [ ] Contact linked to organization and correctly retrieved.
- [ ] Opportunity/contribution follows approved workflow.
- [ ] Meeting and follow-up create visible task; overdue status correct.
- [ ] Dashboard reflects stored records and approved rules.
- [ ] Invalid or unauthorized operations rejected.
- [ ] Staging demo, setup steps, tests and deployment notes delivered.
