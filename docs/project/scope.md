# MVP scope options — not yet approved
## Track A: Data and reporting foundation
Relational schema, data dictionary, approved sample-data loader, validation and deduplication, documented SQL KPIs, a simple BI dashboard, reproducible tests and handoff.

**Not included:** Custom authenticated web CRM, automated workflow emails or production SaaS.

## Track B: Operational CRM MVP
Track A components **plus** staff-facing organization/contact management, sponsorship pipeline or approved financial tracking, activities and follow-up tasks, authenticated access and a basic dashboard, with deployment and testing.

## Potential Phase 2 / later modules
Sponsor interests, programs and recipients, mentorship, membership, advanced documents, six full report categories, WordPress sync, Gmail activity capture and native mobile apps.
